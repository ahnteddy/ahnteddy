STEP 2 · HACKATHON CHEATSHEET

시액조제일지 파싱 가이드

프론트단에서 파싱 후 MISO로 전달하는 프로세스

왜 프론트에서 파싱하나요?
MISO API를 호출하기 전(네트워크 전) 단계에서 파싱하므로 속도가 더 빠릅니다.
전체 원문 데이터 대신 파싱된 구조화 데이터를 넘기면 AI 응답 품질도 올라갑니다.
1
LLM에 요청할 때 전달할 것
▲
page.tsx 와 route.ts 파일만 넘겨주면 됩니다
MISO API 가이드는 넘기지 않아도 됩니다. 파싱은 MISO 호출 이전 단계이므로 불필요합니다. 속도가 느리다면 다른 채팅방을 쓰세요.
파일이 길 경우 하나씩 따로 붙여넣고 "이해만 하고 있어. 대답은 안해도 돼" 라고 해도 됩니다
LLM 요청 프롬프트 예시 
아래는 내 page.tsx와 route.ts야.
백엔드로 던지기 전, 프론트 단계에서 시액조제일지 텍스트를 파싱해줘.

조건:
1. 파싱 결과를 JSON 형태로 구성할 것
2. 카드 형식으로 목록 표시할 것
3. 카드에는 시액명 + 시액조제번호만 표시
4. 카드 클릭 시 상세 데이터를 시각화할 것
5. 유효기한은 조제일로부터 며칠인지 함께 표시할 것
6. 올바른 형식이 아니면 alert으로 안내할 것

2
파싱 구조 알려주는 방법
▲
실제 시액조제일지 예시 텍스트를 LLM에 붙여넣고, 어떻게 파싱하고 싶은지 설명합니다
한 번에 모든 조건을 줄 필요 없습니다. 하나씩 쌓아가는 방식으로 진행하면 됩니다
예: "시험자랑 시액명만 먼저 파싱해줘" → 확인 → "이제 유효기한도 추가해줘"
⚠ 파싱 후 반드시 디버깅으로 값들이 올바르게 나오는지 확인할 것. 파싱이 어긋나면 MISO 응답도 틀려집니다.
3
카드 UI 구성
▲
붙여넣기 1회 = 카드 1장 추가 / 카드 우측 삭제 버튼 / textarea에서 Ctrl+Enter로 직접 입력 등록
카드에 표시되는 문구 — 시액명 + 시액조제번호
예: 0.005M 수산화나트륨 메탄올 용액 (HWS-60327-03)
카드 클릭 시 → 모달로 상세 정보 표시
4
모달 상세 정보
▲
시액명, 시액조제번호, 시험자, 조제일, 유효기한
유효기한 표시 예: 2026-06-26 (조제 후 91일)
조제 내역 테이블 컬럼
