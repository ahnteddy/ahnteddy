v0 → GitHub 연동 & 배포
▲
GitHub 레포지토리(코드 저장소)와 연동하면 코드 수정 즉시 자동 배포됨
— v0에서 직접 수정하는 것보다 빠르기 때문에 이 방식을 권장. v0로 배포 후 진행하세요.
1
우측 상단 Publish 클릭 → Create Repository 클릭
2
GitHub Sign In (구글 연동)
3
Username 입력

5
Authorize Vercel 클릭

Install Vercel 팝업 뜨면 하단 Install 클릭
7
Vercel에서 Create Repository 클릭
8
하단에 GitHub Connected 팝업 뜨면 클릭
→ 팝업 사라지면 github.com 접속해서 레포지토리 확인
✓ 여기까지 완료되면 v0 작업물이 GitHub 레포지토리(저장소)에 올라가고 Vercel 자동배포 연결 완료. 이후 GitHub에서 파일 수정 → 저장하면 Vercel이 자동 재배포함

▲
1
edu.miso.gs 접속 → 로그인 (인증코드 입력)
2
플레이그라운드 → 앱 만들기 → 워크플로우 선택

→ 발행해야 외부 서비스에서 워크플로우 호출 가능

우측 상단 로켓 모양 (앱 공유하기) 클릭 → 다른 서비스와 연결하기 → API 키 생성 → 확인

GitHub에서 route.ts 생성
▲
route.ts는 프론트(page.tsx)와 백(MISO API) 사이의 연결 다리 역할. v0가 이미 생성해놨다면 새로 만들지 말고 기존 파일을 수정할 것
1
github.com 접속 → 해당 레포지토리(저장소) 클릭
2
app/api/miso/route.ts 파일이 있는지 확인
있으면 → 파일 클릭 후 연필 아이콘으로 수정 / 없으면 → app 폴더 → Add file → Create new file → 파일명에 api/miso/route.ts 입력
3
LLM에 아래 정보를 넘겨서 route.ts 코드 받기
LLM에 넘길 정보 
route.ts 파일을 만들어줘.

- 엔드포인트: /chat  (⭐ /chat-messages 아님, /workflows/run 아님)
- MISO API URL: (위에서 복사한 값)
- API KEY: app-여기에비밀키입력
- 입력변수명: input
- 응답 파싱: res.text() 먼저 받고 JSON.parse() 할 것
- 응답값: data?.answer
- response_mode: "blocking"
- conversation_id: ""
- user: "user"

⭐ 명세서에 mode라고 나와있어도 실제 파라미터는 response_mode임 (명세서가 잘못되어있음)
4
받은 코드를 GitHub 파일에 붙여넣기
5

또는 Ctrl+S
