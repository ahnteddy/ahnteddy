GitHub에서 route.ts 생성 (프론트 ↔ MISO 연결 다리)
▲
route.ts는 프론트(page.tsx)와 MISO API 사이의 연결 다리 역할. v0가 이미 생성해놨다면 새로 만들지 말고 기존 파일을 수정할 것
1
github.com 접속 → 해당 레포지토리(저장소) 클릭
2
app/api/miso/route.ts 파일이 있는지 확인
있으면 → 해당 파일 클릭 후 연필 아이콘으로 수정 / 없으면 → app 폴더 → Add file → Create new file → 파일명에 api/miso/route.ts 입력 (슬래시 치면 폴더 자동 생성)
3
LLM에 아래 정보를 넘겨서 route.ts 코드 받기⭐
LLM에 넘길 정보 목록 
(상황설명하며) route.ts 파일을 만들어줘.

- 엔드포인트: /chat  (⭐ /chat-messages 아님, /workflows/run 아님 주의)

- MISO API URL: 위에서 복사한 값
- API KEY: app-여기에비밀키입력
- 입력변수명: input
- 응답 파싱: res.text() 먼저 받고 JSON.parse() 할 것
- 응답값: data?.answer
- response_mode: "blocking"
- conversation_id: ""
- user: "user"

주의: ⭐ 명세서에 mode라고 나와있어도 실제 파라미터는 response_mode임(명세서가 잘못되어있음)
4
받은 코드를 GitHub 파일에 붙여넣기
5
Commit changes 클릭 → Commit changes 클릭
또는 Ctrl+S
✓
커밋하면 Vercel이 자동 재배포됨
